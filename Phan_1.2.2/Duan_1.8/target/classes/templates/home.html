Thử REST API

  • GET /api/books: lấy tất cả sách (JSON)
  • GET /api/books/1: lấy sách có id = 1
  • GET /api/books/title/Clean Code: tìm theo tên
  • POST / PUT / DELETE /api/books: cần tài khoản admin / admin123
  • H2 console: JDBC URL jdbc:h2:mem:bootapp, user sa, mật khẩu để trống
