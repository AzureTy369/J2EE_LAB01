# Phần 1.1.3 - Bài tập làm thêm

Phần này gồm sáu dự án theo yêu cầu trong tài liệu:

- `Duan_1.1`: Spring Container, cấu hình bean bằng Java.
- `Duan_1.2`: So sánh bean singleton và prototype scope.
- `Duan_1.3`: So sánh `SCOPE_SINGLETON` và `SCOPE_PROTOTYPE`.
- `Duan_1.4`: Đọc cấu hình bằng `@Value` và `@PropertySource`.
- `Duan_1.5`: Dependency Injection bằng `@Autowired` và `@Qualifier`.
- `Duan_1.6`: Tạo custom scope lưu bean theo thread.

Mỗi dự án là một Maven project độc lập, dùng Java 17 và Spring Boot 4.1.1.
